# Donnell's SignGuy AI Documents

This folder is reserved for Donnell's plain-language owner documents. It should contain planning, progress, feature-audit, and decision documents that help Donnell understand what has been completed and what should happen next.

Do not put application code, developer evidence, automated test output, migrations, temporary notes, or build artifacts in this folder.

## Folder contents

These are the detailed code-based documents already created to explain what the MVP currently has in each main section:

## Rule for future updates

When a section is completed, update its outline instead of creating another similarly named document. Mark each step as completed, record the related branch or pull request, and add a short plain-language description of what changed.
