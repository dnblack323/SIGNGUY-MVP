## On an order

Each order has a **Files & Artwork** tab for the artwork and reference files for that job. The **Documents & Approvals** tab holds documents and the approvals that go with them.

## The document library

**Documents** (`/documents`) is the shared file library. Files are **private by default** and every download is authenticated, so a link on its own does not expose a file.

## Artwork status

Order items track whether artwork is customer-supplied, whether design is required, and the artwork and proof status. Use these so the production team knows whether a job is ready to print.

## Tips

- Name files with the customer and order so they are easy to find.
- Send proofs through [approvals](/help/docs?article=approvals-and-proofs) instead of by email so the decision is recorded on the order.
